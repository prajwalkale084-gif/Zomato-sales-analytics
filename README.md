# Zomato Sales Analytics

An end-to-end Python data analytics project that cleans, processes, and analyzes Zomato sales and order performance data.

## 📁 Project Structure

- `app.py` - Core analytics application and execution pipeline.
- `pop.py` - Primary order processing and cleaning logic.
- `sop.py` - Secondary order processing routines and helper functions.
- `.gitignore` - Prevents large CSV datasets from being tracked in Git.
